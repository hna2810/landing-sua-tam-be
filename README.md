# Landing Page Sữa Tắm Gội Bon Bon Cho Bé

Theme landing page cao cấp dành cho sản phẩm **Sữa Tắm Gội 2in1 Bon Bon Cho Bé** thương hiệu Home Care Việt Nam.
Website: [suatambe.bonbonhomecare.vn](https://suatambe.bonbonhomecare.vn)

## Tính năng nổi bật
- **Animations GSAP 3.12.5**: Tương tác mượt mà với ScrollTrigger, Draggable, ScrollToPlugin.
- **Hero tương tác**: Bong bóng bóp nổ tích điểm, lọ sữa tắm Bon Bon kéo thả đàn hồi, chú vịt tắm kêu quạc quạc.
- **Pain points flip cards**: Thẻ lật 3D chạm để lật xem giải pháp.
- **Compare slider**: Thanh trượt so sánh sữa tắm thông thường vs Bon Bon.
- **Ingredients minigame**: Trò chơi kéo thả thành phần pha chế vào lọ, từ chối Paraben.
- **Horizontal benefits**: Cuộn ngang mượt mà trên desktop ghim cố định.
- **Baby skin quiz**: Quiz 4 câu hỏi chẩn đoán da bé và tự động điền form.
- **Vòng quay may mắn (Lucky wheel)**: 100% trúng quà, hiệu ứng pháo hoa confetti rực rỡ.
- **Lead form đa năng**: Đếm ngược ưu đãi, lưu đơn vào WP database, gửi email tức thì, đồng bộ webhook Pancake/Google Sheet, tích hợp sẵn Facebook Pixel, Google Analytics 4, TikTok Pixel.
- **Tùy biến ACF**: Cấu hình Hotline, Zalo, Webhook, Email nhận đơn, Mã Pixel dễ dàng trong WP Admin.
